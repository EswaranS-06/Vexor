Install on a Linux host

        
Docker Engine 24+ with Compose v2, systemd, and the RAM the simulator shows for your stack.

      

      
    
        
  1. 
          
    Clone and install
    
          
    Creates .env, generates every password, the cluster key and the certificates, removes the demo users, and starts the stack.
    
          
    git clone https://github.com/EswaranS-06/Vexor.git
cd Vexor && sudo ./vexor install
    
        
    2. 
        
  2. 
          
    Turn on self-healing
    
          
    Boot service, a watchdog every 5 minutes, an hourly doctor --fix, daily backups and maintenance.
    
          
    sudo ./vexor daemon install
    
        
    3. 
        
  3. 
          
    Add what your SOC needs
    
          
    Each one has its own status, test and day-to-day commands. The simulator's .env + commands tab writes these for your pick.
    
          
    vexor soc both
vexor suricata enable && vexor suricata test
vexor n8n enable && vexor n8n connect && vexor n8n workflow
