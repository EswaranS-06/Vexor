A SOC stack that tells you what broke, and fixes it.

Vexor runs Wazuh, the Elastic Stack, or both on one Docker host. One command sets it up; the same command checks it every hour and repairs the failures that usually take a SOC team an afternoon.

git clone https://github.com/EswaranS-06/Vexor.git && cd Vexor && sudo ./vexor install

    It fixes what usually breaks.

    Every check below came from a real failure while building and running the stack. vexor doctor runs about sixty checks; the hourly health timer repairs the ones it can and writes an AI-ready report for the rest.

    • Demo users log in with public default passwordsRemoved from the indexer and pushed with securityadmin
    • A manager ignores your edited ossec.confRecreated, because the image only applies mounted config to a fresh container
    • An empty .env value followed by a commentComment moved to its own line, since Compose would use it as the value
    • Suricata runs with 0 signaturesRules downloaded, ownership fixed, hot-reloaded
    • An image download fails on a TLS errorEach missing image retried with back-off
    • Elasticsearch stays yellow on one nodeReplicas set to 0 and the index template corrected

    Add sensors and tools with one flag.

    Set a tool to true in .env. Vexor wires it in and serves every web tool over HTTPS through nginx, with the dashboard's certificate.

    Suricata

    IDS on your interface. High-severity alerts reach Wazuh at level 10.

    SURICATA=true

    Zeek

    DNS, HTTP, TLS and SSH logs, with notices raised as alerts.

    ZEEK=true

    Grafana

    A Wazuh alerts dashboard on a read-only indexer user.

    :53000

    Portainer

    Every container on the host, with the admin password preset.

    :59443

    n8n

    Workflows for enrichment and notifications.

    :55678

    Start in three commands.

    1. Install

      Creates .env, passwords and certificates, then starts the stack.

      sudo ./vexor install

    2. Keep it healthy

      Adds the watchdog, the hourly health check, daily backups and a login summary.

      sudo ./vexor daemon install

    3. Enroll an agent

      Prints a copy-paste install command for Windows, Linux or macOS.

      vexor agents enroll-cmd windows
